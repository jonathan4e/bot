# AllBot

AllBot is a discord bot that was made to elimanate the need of having multiple discord bots in a server, and limiting it to one.

It comes with 10+ commands.

Includes:

- ping
- welcomer
- AI chatbot
- joke
- rock paper scissors
- coinflip
- diceroll
- quote
- reminder
- weather
- serverinfo
- time

----

## Running the bot

To run the bot,

- Clone this repository to your desired furectory of choice.

```bash
git clone https://github.com/jonathan4e/bot.git
```

- Install all the required modules from `requirements.txt`

```bash
pip install -r requirements.txt
```

- Add your discord bot token and gemini api key into the `.env` file.

- Run `bot.py` directly, or through a container (like Docker)

That's it! AllBot is ready for your server!
